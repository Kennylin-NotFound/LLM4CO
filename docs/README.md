# 工程文档导航

本目录保存 LLM 优化求解系统的设计、验证、研发记录和后续计划。当前对外面试口径不在这里维护，统一以项目根目录的 `../../06_技术岗位面试支撑材料.md` 为准。

## 目录职责

| 位置 | 内容 |
|------|------|
| `design/` | 当前系统设计与方法论基线 |
| `audit/` | 创新性审计、完整管线解释与验收说明 |
| `research/` | 相关工作与历史研究草案，不作为当前面试口径 |
| `planning/` | 工程任务计划、研究 TODO、发现与阶段进度 |
| 当前目录下的其他文件 | 与代码直接配套的实验协议、运行状态和证据说明 |
| `../archive/` | 历史中间产物，不作为当前证据入口 |

## 常用入口

- 系统完成度与证据边界：`system_completion_status.md`
- 完整方法与数据流：`audit/07_完整管线与方法论验收说明.md`
- 方法设计基线：`design/02_系统设计与方法论方案.md`
- 后续实验重启：`planning/08_后续研究TODO与实验重启指南.md`
